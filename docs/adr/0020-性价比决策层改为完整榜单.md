# ADR-0020：性价比决策层改为完整榜单

- 状态：已接受（2026-11-11）
- 关联：修订 [ADR-0019](0019-成本调整综合分与无脑选决策层.md) 的展示决策；算法与口径不变

## 背景

ADR-0019 交付的「性价比首选」卡片在认证态只输出单条推荐（一个榜首行）。owner 反馈需要一整个性价比榜单，而非单条数据。

## 决策

1. **卡片扩为完整榜单**：入池（全证据候选）模型全部按 λ=10 调整分降序排列，复用榜首行视觉；认证语义从「是否输出内容」收窄为「第 1 名是否加冕首选徽章」。未认证时榜单照常展示但第 1 名不加冕，保留 λ 分档区间表——排序是信息展示，加冕宣称才需要认证，不违背「未认证不设单一榜首」裁决。认证的 argmax 不变性（含 λ=0 档）保证认证态下调整分榜首恒等于综合分榜首，两种排序在加冕处一致。
2. **池外模型灰显列在榜单尾部**，行内标注剔除原因（最低百分位 / 仅 N 榜实测），取代脚注文字列举（池外常达 20+，文字列举不可扫读）；池外不占名次编号——池成员资格是门槛，混排会暗示跨门槛可比。
3. **主排行榜不加调整分列**；卡片内嵌完整榜单后，右上角「完整榜单」跳转按钮（指向综合口径主表）删除。

## 备选与取舍

- 主表加调整分列：主表契约是综合口径融合排名（ADR-0010/0015/0016），且池外模型无有效排名、该列大多为空，把两个决策层混进一张表得不偿失，不采纳。
- 未认证维持现状不出榜单：同一输入类型出现两种卡片形态（认证出榜单、未认证塌缩成分档表），排序信息无端消失，不采纳。

## 后果

纯前端派生展示层变更：`adjustedScores`/`certifyNoBrainer` 算法、λ 与短板线参数、融合排名、CSV 导出、分享链接、服务端 API 完全不变。卡片新增排序确定性规则（调整分并列时按综合分降序、名称升序）。

## 修订记录

- 2026-11-11（当晚）：owner 反馈「不要求成为榜首，但不入池太离谱」——未入池段从「名字 + 原因」升格为**续排名**：按同一排序键（调整分降序，并列综合分/名称）排序、逐行显示调整分与未入池原因，段头标注「按性价比续排，无加冕资格」。榜（展示）与冕（认证断言）彻底分离：短板线 40 与 4/4 覆盖门只决定加冕资格，不决定是否出现在榜单上；`ranked` 与 `gatedOut` 收敛共用同一比较函数。口径零改动（实证：短板线 25–40 区间池不变，覆盖门 3/4 会使认证塌方，均维持原裁定）。

## 修订记录

- 2026-11-11（晚）：未入池段升格为续排名（按同一排序键续排、显示调整分与原因、无加冕资格）——owner「不要求榜首但要上榜」；见 docs/adr/0021 批次。
