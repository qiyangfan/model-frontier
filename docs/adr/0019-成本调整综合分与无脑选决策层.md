# ADR-0019：成本调整综合分与无脑选决策层

- 状态：已接受（owner 2026-11-10 点名授权，履行 ADR-0003 的「均衡镜头类派生列须 owner 点名」条款）
- 日期：2026-11-10

## 背景

现有看板只有帕累托前沿（可选集）与成本并列展示，缺少回答「新模型来了无脑选谁」的决策层。owner 在 harness-bench 项目迭代出公式并经真实市场数据校准，要求反哺本站。纯帕累托存在已知缺陷：前沿容纳「贵一万倍换 1% 提升」的怪物，且前沿多点时无单一答案。

## 决策

新增派生层（显示为总览页新卡片 + 纯函数导出），**不修改**现有 composite、名次、前沿成员与任何既有口径（显示与评分分离，宪法第 2 条）：

1. **调整分**：`adjusted = composite − λ × log2(costIndex / 100)`。costIndex 即 ADR-0003 既有三站中位比几何平均（100=池中位）；log2 翻倍计罚（成本差是乘法性的）；λ=10，锚点=10 个百分位点，经 2026-11-10 三榜交叉 21 个真实模型实测市场斜率 9.4±2.7/翻倍校准（市场公允价与显著性锚双源合流，详见 harness-bench `tb2/formula-lab.py`）。语义：花两倍的钱，须强出约一个榜单噪声单位才不亏。
2. **塌方门**：最低源百分位 `< 40` 的模型不入无脑选池（任一维度塌方者不得作无脑默认；门槛值可配置，默认 40）。
3. **无脑选终审 + 认证**：池内取调整分最高者；认证 = 支配一致性自检（被支配者不得反超支配者——`composite − λ·log2` 单调性定理保证，运行时仍自检）+ λ 扫描不变性（λ ∈ [0, 2.5, 5, 10, 20, 40] 全区间 argmax 唯一）。未认证时展示 λ 区间图（哪类用户该选哪个），不伪造单一答案（宪法第 1 条）。

公式三公理：支配一致性（定理保证）、塌方免疫（门）、膝盖收敛（λ 扫描认证 = 最小最大遗憾解）。

## 后果

- 总览页新增「无脑选」卡片：认证结论 + λ 扫描表 + 塌方门剔除名单（诚实 reason 风格）。
- 调整分只依赖既有 composite 与 costIndex，无需新数据摄取；模型覆盖不足（composite/cost 缺失或源百分位不足）时按既有 reason 风格明示，不补零不虚构。
- λ=10 为写死常量（简单优先）：若未来榜单构成大改导致市场斜率漂移，修订本 ADR 更新校准记录。
- 已知取舍：调整分对「cheap-but-weak」不给惩罚加成（其成本低于中位会得正加成，但 composite 低故仍居后）；「无脑选」语义面向日常开发默认场景，预算敏感用户应看 λ 区间图自行选点。

## 修订记录

- 2026-11-11：塌方门补充证据完整性要求——池成员资格要求全量榜单覆盖（行级 `complete`：4 榜全部有效实测分；`adjustedScores` 内 fail-closed，缺字段按不完整处理）。理由：认证文案「榜首对任何预算观感都稳健」是对全维度的断言，部分覆盖模型「未观测到塌方」≠「无塌方」，缺一维证据即断言超纲；诚实的部分覆盖方案需要额外披露层（覆盖徽标 + 「已测维度」限定文案），比严格门代码更多且断言更弱，不采纳。实证（2026-11-10 本地快照，783 模型、50 个有 composite）：全量覆盖 ∩ 塌方门 = 8 个模型（含 Opus 5.5、Sonnet 5.5、Gemini 4 Argon、GPT-6.1 Sol 等前沿级），λ∈[0,40] 全区间 argmax 不变、认证通过；放行部分覆盖时池 18 个、λ=10 起分叉（最强但缺一维实测的模型把「无脑选」变成「按预算自选」）——证据不全的前沿恰是认证无法收敛的根源，剔除后全证据前沿自身收敛出唯一解。空池时卡片诚实展示原因，随源站补测自动恢复。评分层「默认纳入实测、覆盖不加分」原则不受影响：决策层不改任何分数、名次与前沿成员，只设「默认推荐」的证据标准。owner 授权代理裁定（本轮会话）。
- 2026-11-11：展示更名——总览页卡片「无脑选 / NO-BRAINER PICK」更名为「性价比首选 / PERFORMANCE × COST」，并新增定位副标（性能与成本的综合权衡、帕累托式，非纯能力榜；每贵一倍须明显更强才不亏）。算法与决策层语义不变，「无脑默认选」保留为认证文案中的语义描述（认证通过 = 无论多在乎成本首选都是同一个）；内部池名随文案收敛为「首选池」。理由：站外读者第一眼必须识别这是性能与成本的综合口径——避免把榜首误读为纯能力排名，也预防「公认便宜弱模型为何登顶」的质疑（塌方门已从构造上排除任一维度塌方者，λ 区间表中高 λ 档首选是预算敏感视角的如实展示，副标注明 λ 越大越看重成本）。
- 2026-11-11：用户可见文案弃用「塌方门」黑话，统一改为「短板线／存在短板」。概念澄清：「塌方」源自 harness-bench（同一模型在不同 harness 下表现大幅分化）；本项目的同构现象是跨榜单短板——四张第三方榜单（AA / Vals / LiveBench / Arena）即四种测量体系，任一榜单百分位过低即换体系露馅，概念成立、门槛保留。措辞修正：本门测的是各榜最低百分位的绝对下限（min ≥ 40），不是分化幅度（max − min），故对外称「短板」比「塌方」更准确。代码内部 λ、argmax 等参数与定理名保留，用户可见文案一律用「每贵一倍扣几分」「分档复核」等白话表述。门槛算法、取值与全量覆盖要求均不变。
- 2026-11-11：防盲选踩坑三件套——(1) 未认证态不再展示单一榜首：多数决 pick 仅保留为内部字段。交叉点靠近低 λ 时（如每贵一倍扣 4 分处翻转），6 档多数决会把中庸便宜模型顶上带名次徽章的榜首位，构成盲选陷阱；此后「榜首」仅在认证态（或唯一候选态）存在，未认证态以分档区间表为主角（连续同选档合并为「每贵一倍扣 X–Y 分 → 模型」区间行）。(2) 认证态榜首语义显式化：认证要求含 λ=0 在内全区间 argmax 不变，而 λ=0 的 argmax 即池内 composite 最高者——故认证榜首恒等于「通过全量实测与短板筛选的候选中综合能力最强者」，前沿分近、便宜前沿登顶、顶级最贵登顶、中庸偏高四类市场形态下盲选均不踩坑（中庸模型只能在未认证高 λ 档出现且不再冠以榜首）。(3) 榜首行新增成本展示（复用 costFormat composite 倍数），盲选前看得见价格。附数学注记：调整分对 λ 线性，上包络顶线更替只能发生在交叉点且必改变其所在区间端点的 argmax，故 6 格点扫描对 [0,40] 连续区间的认证是精确等价而非近似。另增 poolSize=1「唯一候选」态文案，避免「认证通过」的空真表述。
- 2026-11-11（晚）：**每榜短板线移除，池资格改纯综合锚**——见 docs/adr/0021。owner 三点质疑驱动：① 40 取值无校准记录（与 λ=10 的市场斜率校准不同，仅为判断默认值）；② 敏感性实证：floor 取值 0~50 时认证与 pick 恒不变（只改池名单，[25,40] 平台期），短板线从未影响「谁是首选」；③ 锚点原则——每榜否决权包含 Vals 经济任务、LiveBench 分类均分（含数学/写作/哲学等）等与使用场景无关的专项轴，任何取值都是锚错专项。移除后池（4/4 全测）9→18，认证与 pick 不变。「塌方门」概念源自 harness-bench（同一模型×不同 harness×同类任务的稳健性），移植本项目后语义已变为跨能力轴的绝对下限断言，本次连同该断言一并移除：池资格只保留 4/4 全量覆盖（全称断言需全量证据，覆盖放宽至 3/4 或 2/4 实证认证永久塌方，且与主榜 ≥2 榜准入的天梯语义失去差异化）。floorPct 保留为描述字段。4/4 覆盖裁定（本日上条）不受影响。
