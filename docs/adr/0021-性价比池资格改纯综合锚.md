# ADR-0021：性价比池资格改纯综合锚（移除每榜短板线）

- 状态：已接受（2026-11-11）
- 关联：修订 [ADR-0019](0019-成本调整综合分与无脑选决策层.md)（移除「塌方门/短板线」，4/4 覆盖门维持）；展示形态见 [ADR-0020](0020-性价比决策层改为完整榜单.md)

## 背景

owner 质疑卡片结果引出三点：① 短板线 40 的取值依据——ADR-0019 只有原则叙述与「默认 40」，无校准记录（λ=10 有 21 模型市场斜率 9.4±2.7 校准，短板线没有）；② 认真评估覆盖门放宽到 2/4 的后果；③ 决策层锚点必须「要么综合，要么对的专项（编程/终端）」，不得锚错专项。短板线的每榜否决权包含 Vals 经济任务与 LiveBench 分类均分（含数学/写作/哲学等与使用场景无关的轴）——无论取值多少，否决轴本身错锚。

## 证据（2026-11-11 真实快照离线审计，`work/value-gate-final-audit.mjs`）

1. **短板线敏感性（覆盖 4/4）**：floor 50/45/40/35/30/25/20/15/10/5/0 → 池 7/8/9/9/9/9/12/15/15/16/18；**全部取值下认证通过、pick 恒为 gemini4carbon**。短板线取值只改池名单，从未影响「谁是首选」。[25,40] 为平台期，40 无特殊地位。
2. **覆盖 × 短板线组合**：认证塌方（✗，多数决 pick=claudefable52）只由覆盖放宽引起——覆盖≥3 或 ≥2 时无论短板线有无，认证全 ✗；覆盖 4/4 时无论短板线有无，认证全 ✓。
3. **覆盖选择性偏差**：2/4 模型恰好只缺可能暴露弱点的榜（Muse Ember、Qwen 3.8 Max 0902 均仅 [aa, vals]）——部分覆盖的 composite 与全量覆盖不可比，放入同一排名段会以「未测到弱轴」虚高名次。
4. **移除短板线的实际影响（覆盖 4/4）**：池 9 → 18（GLM 5.3 Flash、GPT-6 Luna、Kimi K3、Gemini 3.8 Flash、Step 5 Preview、Grok 4.7、Inkling、Mistral Large 4、Claude Haiku 5.5 等 4/4 全测模型获得正式名次），认证 ✓，pick 不变。

## 决策

1. **移除每榜短板线**（ADR-0019「塌方门」，含 `gatePct` 参数与 reason 分支）：池资格 = 有输入（综合分 + 成本）且 4/4 全量有效实测分——纯综合锚（ADR-0003 composite），无任何专项否决。「40 的合理取值」随门移除消解：敏感性曲线与语义分析（50=每榜中位以上 / 25=不在垫底四分位 / 40 无语义）备查如上，任何取值都与认证无关且错锚专项。
2. **4/4 覆盖门维持**：全称断言（「通过全量实测的候选中综合能力最强」）需要全量证据；覆盖放宽会使认证永久塌方（证据 2），且与主榜（≥2 榜准入的天梯语义，ADR-0011）失去差异化——决策层的存在意义是「无脑默认选谁」，2/4/3/4 使其退化为带成本罚的主榜翻版。实测不全的模型已由 ADR-0020 续排段完整呈现（调整分 + 覆盖标注 + 无加冕资格），可见性不依赖池资格。
3. **认证语义与机制不变**：支配一致性自检 + λ∈[0,2.5,5,10,20,40] 扫描 argmax 不变；认证榜首恒等于全证据候选中 composite 最高者（含 λ=0 档的必然结果）。
4. `floorPct`（最弱已测榜百分位）保留为描述字段，不再参与资格判定；编程/终端专项层（LiveBench coding suites × 成本，数据已在快照、覆盖 34 模型）登记为待立项，未实施。

## 后果

- 4/4 全测但弱项榜垫底的模型（最低百分位 3~23）进入正式排名获得名次；实测不全模型全部落续排段（该段原因只剩「仅 N/4 榜实测」一种）。
- `adjustedScores` 签名去掉 `gatePct`；返回值去掉 `gatePct` 字段。融合排名、CSV、分享链接、服务端 API 不变。
- 风险接受：池内存在某榜垫底 3% 的模型（如 Inkling floor=3）——其综合分与调整分自然靠后，不加冕即无盲选风险；若未来需要「无弱轴」口径，应作为独立视图立项而非恢复错锚否决。
