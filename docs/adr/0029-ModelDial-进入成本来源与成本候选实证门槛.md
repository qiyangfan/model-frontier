# ADR-0029：ModelDial 进入成本来源（四源几何平均）与成本候选实证门槛

- 状态：已接受（2026-11-26，owner 质询「成本评判标准会不会过于苛刻」触发复核，授权代决）
- 关联：推翻 [ADR-0026](0026-ModelDial-成为第五评分来源.md) 决策第 2 条的成本裁定；修订 [ADR-0017](0017-成本几何平均口径.md) 确立的「三源几何平均」成员数；SuperCLUE 成本维持排除（见 [ADR-0028](0028-SuperCLUE-成为第六评分来源.md) 修订记录）

## 起因

owner 2026-11-26 质询：ModelDial 成本被否、SuperCLUE 成本也被否，「会不会以后的都被你否，条件会不会过于苛刻」。此前两个否决共用同一条理论依据（ADR-0026：「题量小没有平均效应，不同题套没有换算公式」），该依据从未被实测检验过。本次补上检验，判据在跑数之前预登记，防止看完数据再定标准。

## 预登记判据（新门槛标准，今后成本候选一律照此机械执行）

成本轴喂的是「相对成本指数」：各源成本先除以**该源自己的**中位数（币种、量纲在这一步自动消去），再对可用源取几何平均。因此候选源唯一需要证明的是：**它给出的模型间相对成本排序，不比在籍三源互相之间的偏差更离谱**。

- **基准包络**：在籍三源（AA/Vals/LiveBench）两两相比——共同模型上，每源归一后取比值，报告居中偏差的中位绝对值（MAD，单位「倍数」）与秩相关 ρ。
- **门槛**：候选源对三源各自成对检验，全部满足 MAD ≤ 1.5 × 在籍最差对 MAD，且 ρ ≥ 在籍最差对 ρ − 0.1。
- **数据口径**：快照 2026-11-25；族内多路由取中位（稳健性另用「最高分路由」复算）；n<4 的成对检验不判。

这条标准自限于在籍成员自身的噪声水平：候选只需与「已经进门的人」一样一致，不存在可以无限收紧的自由裁量。

## 实测（脚本与中间数据见 /tmp/superclue-research/cost-audit.mjs）

**基准包络（在籍三源互相，n=28–31）**：

| 成对             | MAD         | ρ         | 最差单模型偏差 |
| ---------------- | ----------- | --------- | -------------- |
| aa ↔ vals        | 0.53 倍     | 0.867     | 3.3 倍         |
| aa ↔ livebench   | **0.95 倍** | **0.713** | **4.2 倍**     |
| vals ↔ livebench | 0.42 倍     | 0.878     | 2.7 倍         |

门槛线：MAD ≤ 1.43 倍，ρ ≥ 0.613。**在籍成员自己互相就差这么多**——中位偏差近一倍、最差单模型差 4.2 倍，是成本轴既有的正常波动水平。

**ModelDial（整轮后端评测估算费用，美元，族内取路由中位）**：

| 成对                  | MAD     | ρ                     |
| --------------------- | ------- | --------------------- |
| modeldial ↔ aa        | 0.86 倍 | 0.836                 |
| modeldial ↔ vals      | 0.63 倍 | **0.917**（全表最高） |
| modeldial ↔ livebench | 0.58 倍 | 0.882                 |

改用「最高分路由」成本复算：MAD 0.58–0.86、ρ 0.804–0.907，结论不变。**六项检验全部过门槛**——ModelDial 与在籍三源的一致性反而优于在籍三源彼此之间。

**SuperCLUE（编程单题成本，元）**：MAD 0.94–1.19 倍（在门槛内），ρ = 0.706（对 aa）/ **0.586（对 vals，低于 0.613）** / 0.842（对 livebench）→ 按判据不过。源内跨维检验（编程维 vs 数理/指令/幻觉/长文维，n=20）：ρ = 0.776/0.789/0.689/0.684——同一批模型换个题目维度，相对成本排序就动到 ρ≈0.7，证实其成本确实是「题目组合敏感」的测量。定性为**边界未过**（差距在 n=15 的抽样噪声内），非明确劣质；今后任何一期数据按同判据复测，三对全过即可进入。

**当初理论依据为什么错了**：ADR-0026 以「题量 5 vs 约 2500」论证无平均效应，实际机制是——ModelDial 的 5 道题每道都是重型代理任务（单题耗时中位 903 秒、单模型单题 tokens 数十万到数百万），**平均化的单位是任务内部成百上千次 API 调用，不是题数**；计价信号远压过题级噪声。n=5 这个「题数」从来就不是正确的样本量单位。

## 决策

1. **`COST_SOURCES` 增加 `modeldial`，成本几何平均三源 → 四源。** 适配器将最高分完整配置的 `metrics.backend.estimated_api_cost_usd` 原值写入 `costTask`。这是跑完整轮后端评测的美元估算费用，按原单位展示。综合成本使用该值与 ModelDial 中位数的比值。
2. **单站成本和预算只提供 AA、Vals、LiveBench。** 两项均以每次任务的美元成本计。ModelDial 提供整轮后端评测费用，`cs=modeldial` / `bs=modeldial` 仍按既有规则回落默认。
3. **成本候选门槛固化为标准**（见上），写入本 ADR 作为今后所有成本候选的机械判据；SuperCLUE 成本维持排除，复测通过即可进入。
4. **影响面（2026-11-25 快照实测）**：现三源有成本的 69 个模型族中，6 个族从「仅一家报成本」升到两家、首次获得成本资格（minimaxm3、hy4preview、claudefable51、gpt56terra、grok46、qwen38）；36 个 ≥2 源族的指数多一票几何平均。成本基准的「共同完整样本」按既有原则随成员数变化：三源全齐 27 家 → 四源全齐 20 家，全榜成本指数中位摆幅 0.68 倍（36 个可比模型中 34 个 >20%、12 个 >50%）——这是锚点换群的系统性水平移动叠加相对排序微调，属「不同基准的倍数不可直接比较」的已知属性，性价比榜与帕累托数值随之整体重算，与第五票接入时 58→65 的名次重排同类。
