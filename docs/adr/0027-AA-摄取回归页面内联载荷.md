# ADR-0027：AA 摄取回归页面内联载荷，加密文件通道退役

- 状态：已接受（2026-11-25）
- 关联：取代 [ADR-0006](0006-AA-数据摄取改用-manifest-加密端点.md) 建立的「页面 manifest → 加密文件」链路；细化 [ADR-0018](0018-AA-摄取接受-Intelligence-Index-v5.0-的覆盖收缩.md) 的覆盖收缩语义；不改 [ADR-0003](0003-量化口径维持现状.md) 的评分口径

## 背景

2026-11-25 定时刷新 AA 报「源站返回 HTTP 404」，其余四源成功，缓存保留（最后成功
2026-11-24）。排查结论：

- 榜单页面本身 HTTP 200，浏览器访客看到的官网完全正常；失效的是 ADR-0006 链路的
  第二步——页面 manifest 指向的 `/data/f41f1a6f60a41444.txt` 404。
- 站点其他页面引用的全部 `/data/*.txt`（首页、模型页共 7 个不同 hash）同样 404；
  带完整浏览器标头与 cookie 仍 404，排除反爬伪装。
- 无头 Chrome 实测：页面渲染 205 行表格、407 个模型链接，但**全程未请求任何
  `/data/*.txt`**——数据已回到 Next.js Flight 内联，模型数组挂在组件参数
  `initialModels` 上（实测 290 条）。加密文件通道被源站整体废弃并删档。

历史是绕了一圈：2026-10-17 之前数据本就在页面 Flight 里（键名 `models`），ADR-0006
记录的改版把它挪进加密文件并删了页面内联；本次改版又挪了回来（键名
`initialModels`），并删除了文件。区别在于：旧内联只有 273 条当前配置，这次的内联是
当前榜的完整口径（含推理档位拆分），而全量历史载荷不再有任何通道提供。

## 决策

1. **摄取改为「抓页面 → 拼 Flight 分片 → 切 `initialModels` 数组 → parseAA」。**
   `aaFlightText(html)` 把 `self.__next_f.push` 分片（JS 字符串字面量）用 JSON.parse
   还原拼接；`aaInlineModels(flight)` 在 Flight 文本里做字符串感知的括号配对切出数组。
   删除 `aaManifest` / `decryptAAGzip` / `getBuffer` / `MANIFEST_RE`。每次刷新回到
   1 个请求（ADR-0006 期为 2 个）。
2. **字段映射随载荷更名**：`speed ← outputSpeed`（原 `medianOutputTokensPerSecond`）、
   `latency ← timeToFirstToken`（原 `medianTimeToFirstTokenSeconds`）、
   `url ← release.slug`（原顶层 `slug`）。其余映射不变。`estimated` 映射保留：源站
   不再披露 `intelligenceIndexIsEstimated`，行级恒为 false；「纳入估算」开关对 AA
   失效（该开关默认关，默认展示不受影响），字段回归时零改动接回。
3. **载荷收缩接受并记录**：内联只含当前榜配置，实测 290 条（有分 124、开放权重
   183），旧通道全量 766 条（含历史与估算配置）不再有任何通道提供。绝对下限
   `AA_MIN_ROWS` 100 → 200（当前基线的约七成）。
4. **跌幅闸门豁免 AA**：store 的相对比对（上次成功 ≥200 条且本次不足一半即拒绝）
   会把 766→290 的契约迁移永久拒绝——缓存永不替换、报错循环。AA 的完整性改由适配器
   的 `AA_MIN_ROWS` 绝对下限把守；其余四源的闸门不变。ADR-0018 的「按载荷条数不按
   有分条数」比对对其余来源继续成立。
5. **契约校验全部保留**：条数下限、开放权重布尔标记 ≥90%、有效分 ≥5 条（store
   通用）。失败一律明确抛错并保留缓存，不静默回退。

## 后果

- **数据面**：AA 从「全量含历史」变为「当前榜」。主榜、性价比层、成本口径不受影响
  （历史配置默认就被排除）；「纳入估算」开关对 AA 失效。来源卡 notes 改为如实描述，
  不再宣称保留历史条目与估算标记——诚实性红线要求文案跟载荷一致。
- **时效**：恢复刷新后 AA 数据回到 2026-11-25 当前；快照条数 766 → 290。
- **请求次数**：2 → 1，AA 单站刷新耗时相应缩短。
- **风险**：Flight 分片形态与 `initialModels` 键仍是 React/AA 的内部实现，不是官方
  契约。结构再变时按顺序明确报错：找不到 Flight 分片 → 找不到 `initialModels` →
  数组不完整 → JSON 不合法，均保留缓存。
- **测试**：加密管道用例（密钥错误/非 gzip/密钥长度）随 `decryptAAGzip` 删除，换成
  分片拼接、转义感知切割、四类结构变化的用例；跌幅闸门用例改用 livebench 承载大基线，
  并新增 AA 豁免断言。

## 实测记录（2026-11-25）

- 无头 Chrome（本机 Chrome 143，干净档案）：页面 200；表格 205 行、407 个模型链接；
  网络面板除统计/实验配置外无任何数据请求。
- 内联载荷：Flight 分片 3 段合计 0.54 MB；`initialModels` 290 条。字段覆盖：
  `name`/`shortName`/`modelCreatorName`/`isOpenWeights`/`deprecated` 290/290，
  `intelligenceIndex` 124/290，`intelligenceIndexCostPerTask` 109/290，
  `price1mInputTokens`/`price1mOutputTokens` 174/290；
  `medianOutputTokensPerSecond`/`medianTimeToFirstTokenSeconds`/
  `intelligenceIndexIsEstimated`/顶层 `slug` 均不存在。
- 版本标记 Intelligence Index v5.0 仍在页面标题区；内联分数前五（Claude Fable 5.2
  max 64.8、xhigh 62.2，GPT-6.2 Astra max 62.2、xhigh 61.8，Claude Fable 5.2 high
  61.9）与页面渲染文案一致。
