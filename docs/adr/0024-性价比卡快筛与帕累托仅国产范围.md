# ADR-0024：性价比卡快速筛选与帕累托「仅国产」范围（未认证态自适应）

- 状态：已接受（2026-11-11）
- 关联：展示层演进，沿用 [ADR-0020](0020-性价比决策层改为完整榜单.md)/[ADR-0022](0022-编程优先排序视图.md)/[ADR-0023](0023-性价比榜单准入对齐天梯与历史校准缺榜罚分.md)；量化口径（评分、名次、全球前沿成员、CSV、既有 API 字段）零改动

## 背景

owner 四问触发：①编程优先视图数值「那么低」是否该删；②未认证标记块是否还有必要；③要不要加国产/开源快筛；④帕累托等榜单要不要配齐总榜/开源榜/国产榜/国外榜/闭源榜（授权按实用性裁定）。另审查循环实证三处 ADR-0019 时代恒等式文案在罚分语义下已假。

## 决策

1. **编程视图保留，行内标注刻度**。「成绩低」是刻度错位感知：编程分是 0–100 百分位（94=超越 94% 同测模型），综合口径是 ~1500 BT 分。编程是 owner 唯一明确在乎的专项锚点（池内 29/36 有编程分），删除是需求倒退；行内 small 行加「编程百分位」前缀消除误读，排序逻辑不动。
2. **未认证态自适应**。分档扫描全区间同选时，区间表恒指向排序键第 1 名（扫描与排序键在 λ=10 档同构），展开零信息量——压缩为单行「未认证：缺榜罚分下证据不全，第 1 名不加首选标记」；分档分叉时才展开区间表（那才是预算观感改变选择的真实信息）。spec「未认证 Scenario」同步。
3. **性价比卡快速筛选（仅开源/仅国产）**。纯展示层过滤：开源按源站 `openWeights` 严格 true（null=未确认不算）；国产按可确证厂商静态映射（`presentation.mjs`，小写归一；归属存疑厂商不入表——保守偏差优于错误归类）。名次徽章保持全榜口径（筛后跳号是诚实呈现），「首选」徽章仅在第 1 名被筛入时展示。`adjustedScores` 透传 `openWeights`（加性字段；否则裁剪行缺此字段、chip 计数恒 0）。
4. **帕累托探索范围只加「仅国产」，不配闭源榜/国外榜**。子集前沿的价值在「约束型 lens」：国产子集前沿 4 成员中 3 个为全球前沿独有（Kimi K3.1 Pro、MiMo V2.6 Pro/Flash——被国外模型支配但国产约束下是前沿），真实增量。闭源子集前沿 4 成员**全部**在全球前沿上（独有 0），国外榜同理与全球图重复——零增量不配。总榜/开源榜已存在。
5. **`focus` 分享契约新增 `cnOnly` 值**（白名单加性扩展，旧链接全部可解析）；`cnFrontierIds` 展示层派生（`pareto(plotted 国产)`），不进 API 与 CSV（`csvExport` 固定列白名单实证不泄漏）。

## 后果

- 融合排名、CSV 列、既有 API 字段、全球前沿成员全部不变；新增仅展示层字段 `cnFrontier`（探索页 chartRows）与 `openWeights`（调整分行透传）。
- `CreatorChips` 泛化（label/chipPrefix/hint/chipClass/emptyNote props，默认值=主榜原行为；title 保持用 `chip.value`——主榜 label≠value 如 Google→Gemini）；性价比卡用独立锚类 `value-filter-chip`（`creator-chip` 被 E2E 页级定位占用，混用必撞 strict mode）。
- 三处 ADR-0019 时代恒等式文案修正：唯一候选「四榜全量实测」→「具备综合分与综合成本」；认证态删「综合能力最强者」子句（λ=0 argmax = max(composite−罚) ≠ composite 最高者）；未认证态「取值不同首选不同」单因断言 → OR 式双因（violations>0 而 sweep 同选可达）。ADR-0023 Fable 数值勘误 1541→1536（快照 mtime 早于提交，定稿数据即 1536）。
- E2E 竞态修复：新断言点击后立即 `count()` 读到 React 提交前 DOM → 一律 `waitForFunction` 等定态；既有 evidence 套件 reload 后立即断言开关状态读到偏好恢复前 false（实证约 1/3 概率）→ 同法修复，连跑 7×3/3 稳定。
