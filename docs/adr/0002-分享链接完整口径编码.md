# ADR-0002：分享链接把完整口径状态编码进 URL hash

- 状态：已接受
- 日期：2026-10-16（追溯记录既有契约）

## 背景

页面有大量可调口径（权重预设、覆盖门槛、估算开关、成本口径、预算筛选、排行榜筛选、对比选择）。结论复核要求「打开链接 = 进入完全相同口径」。

## 决策

全部口径状态编码进页面锚点（如 `#rankings?p=equal&ms=3`），规则：

- hash 中含 `?` 即完整口径状态；缺省参数一律等于默认值，默认值不写入链接（保持地址短）。
- 非法值丢弃而不破坏页面；只取第一个 `?` 作为页面与参数分隔符。
- 复制链接时按当前状态即时构造，不依赖去抖后的地址栏，避免复制到上一刻口径。

## 后果

- 服务端零状态即可复核；导出 CSV 另附数据时间与口径列，双通道互为备份。
- 新增任何影响结论的口径时，必须同步进 `src/share.mjs` 的编解码与 `tests/share.test.mjs` 的往返测试。
- 排行榜同来源组合对照会改变对照名次与 PK 结果，所选组合以规范来源 ID（`cm`）编码进分享链接；非法组合丢弃。组合因当前数据不可用时保留链接值并显示不可用状态，不静默回退到另一组合。

## 修订记录

- 2026-11-17：**厂商筛选升级多选，新增帕累托快选集合 `pv`（owner 要求「多选，再次点击反选」）**。`cr` 多厂商以 `|` 分隔（`cr=A|B`），无分隔符的单值旧链接按单厂商解码，两种编码互通；`pv` 承载帕累托图厂商快选 chips 集合，独立于自由文本搜索 `pq`，去重、截断 12 个、空集合不占参数。编码只扩展不破坏：旧链接全部可解码，新参数缺省即默认值，核心决策不变。规格与往返测试同步（`openspec/specs/share-link/spec.md`、`tests/share.test.mjs`）。
- 2026-11-25：**四处搜索框统一升级多选 chip，搜索参数 `q` / `pq` / `rq` 支持 `|` 分隔多词条**。多个 chip 与实时草稿按任一命中（OR）生效，单关键词旧分享链接无分隔符，与 `cr` 同口径保持向后兼容，编码结构与既有字段名不变。
- 2026-11-25（二）：**退役死开关分享参数 `est` / `eh` / `ne` / `nh`**。AA 内联回归（ADR-0027）后五源均无估算标记、历史档案通道已撤且代表选取本就在用优先，界面与分析层移除「允许 AA 估算」「排除历史配置」及单榜对应勾选，仅保留真实有效的 `es`（排除过期 / 失败缓存）。旧链接中的 `est`/`eh`/`ne`/`nh` 按已退役参数规范静默忽略、不再写入。
