# 提案：前沿图图例重构（点类开关 + 前沿线三选一）

- 日期：2026-11-17（按已实现行为补记归档）
- 状态：已实现并验收
- 涉及能力：ranking（前沿探索图表展示层）

## 动机

owner 两轮反馈：

1. 三条前沿线（全球 / 开放权重 / 国产）同屏交叉，压住散点与名牌，判为视觉噪音，要求改为三选一。
2. 点类应有「开源 / 国产 / 闭源」三类开关，默认全部展示、单击反选；图例标记实心会被读作「已选中」，要求统一空心。

## 行为前后差异

### 前沿线

- 前：三条线同屏常驻（约束视图隐藏不成立的线），图例中三个线按钮独立显隐。
- 后：三选一——同一时刻只画一条，默认全球前沿；仅开放权重 / 仅国产范围只列成立的那条子集线并自动选中；点的名牌只标注所选前沿线的成员；支配区域仅在选中全球前沿线时出现（切换到其他线不残留）。

### 点类

- 前：开放权重 / 闭源·未确认两类开关（形状编码），国产不是图例维度。
- 后：新增第三开关「国产」，为叠加筛选——国产模型仍按权重保留菱形/圆形，关闭即隐藏全部国产点（不论权重）。三类默认全开、单击独立反选；仅国产范围下该开关不列，且残留状态不生效（否则切进该范围后图会被清空且无控件恢复）。图例标记统一空心（国产为虚线空心圆环）。

## 不变量

- 所有开关只改变显示，不改分数、名次、前沿成员与导出口径。
- 支配区域计数口径不随显示筛选变化（显示筛选不改变口径）。
- 点坐标零改动，不抖动、不错位。

## 实现

`src/Chart.jsx`（POINT_LEGEND / LINE_LEGEND、activeLine 三选一、国产叠加筛选与 `domesticPointsHidden`、`data-chart-visible` 可见点位数、支配区域随全球线门控）；`tests/e2e.mjs`（互斥选中态、国产开关生效、仅国产残留状态回归）；`tests/portal-e2e.mjs`（约束视图与互斥切换）；`README.md`、`docs/adr/0024`、`docs/handoff.md` 同步。

## 规格

ranking spec 增补「前沿图图例」Requirement（点类开关 / 互斥选择 / 约束视图三个 Scenario）；「被支配区跟随鼠标」补充仅在选中全球前沿线时出现，撤下场景由「关闭图例」改为「切换到其他前沿线」。

单测 171/171；覆盖率 98.96 / 91.99 / 97.38；ESLint、Stylelint、Prettier、build 全绿；夹具三套 E2E 全绿；无头浏览器截图核验默认 / 国产线 / 国产线+关国产 / 全球线+关国产四态。回归断言先验证可捕获缺陷：临时移除国产筛选守卫时 E2E 失败，恢复后通过。
